One word, one username — Joni's handle — for make.fun's "One Word,
One Username, One Reward" bounty ($5 in USDC).

```
joni-gunawan
```

12 characters. A real person's handle: easy to say, easy to remember,
two beats in one word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the username deterministically to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), mode 0644, exit 0.
Pure Python standard library. Tests: `python3 -m unittest discover -s tests -v`.
